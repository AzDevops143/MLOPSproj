# MLOps Group Project

## Setup Instructions

Prerequisites:
- Python 3.11+
- Docker
- Kaggle Account
- Weights & Biases Account
- Hugging Face Account

Installation:
```bash
pip install -r requirements.txt
```

Run Inference Locally:
```bash
python src/inference.py
```
